# 🛍️ Shopez – Full Stack E-Commerce Web Application

🔗 **Live Demo:** https://shop-f-indw.onrender.com/

---

## 📌 Overview

Shopez is a full-stack e-commerce web application that provides a seamless online shopping experience. It includes backend APIs, a database, and a dynamic frontend interface.

---

## 🚀 Features

* 🛒 Product browsing and listing
* 🔍 Search and filtering
* 📄 Product details page
* ⚙️ Backend API integration
* 🗄️ Database-driven application
* 📱 Responsive UI

---

## 🛠️ Tech Stack

**Frontend:**

* JavaScript and React

**Backend:**

* Node.js
* Express.js

**Database:**

* MongoDB

---

```id="6hyu3t"
SHOP-EZ/

```

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```id="p3cg0g"
git clone https://github.com/Tanya-yadav-bit/SHOP-EZ.git
cd SHOP-EZ
```

---

### 2️⃣ Install dependencies

Install backend dependencies:

```id="csph06"
cd server
npm install
```

Install frontend dependencies:

```id="64qv57"
cd ../client
npm install
```

---

### 3️⃣ Setup Environment Variables

Create a `.env` file inside the **server** folder and add:

```id="xwhtie"
MONGO_URI=your_mongodb_connection_string
PORT=5000
```

---

### 4️⃣ Seed the database

Run this to insert initial data:

```id="t56vfw"
node seed.js
```

---

### 5️⃣ Run the backend server

```id="2h0lwd"
cd server
npm start
```

---

### 6️⃣ Run the frontend

```id="ts4y0c"
cd client
npm start
```

---

## ▶️ How it Works

1. `seed.js` → populates database
2. `server/` → runs backend APIs
3. `client/` → runs frontend UI
